## 🛠 Local Setup

Clone: git clone https://github.com/RoyalKatsic1/R-Katsic-Wa-Bot.git
cd R-Katsic-Wa-Bot

Install: npm install

Configure http://config.js:
ownerNumber: ['256754214612'],
botName: 'ROYAL KATSIC MD',
prefix: '.',
sessionID: 'RoyalKatsic!H4.....'

Run: node http://index.js

- If sessionID empty, QR will show
- If sessionID set, bot logs in directly
